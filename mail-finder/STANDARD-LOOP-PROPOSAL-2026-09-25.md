## Lessons locked into the loop

### From W1 (deep50 / early)
- Prioritize: BCSC/regulatory PDFs, EDGAR signature blocks (published spelling), DocuSign/ethics/impact PDFs, press mailto, Mercury-class dirs, team person mailto
- Stop early on generics / 403 / parked / wrong entity
- LinkedIn-primary → HITL HOLD (no scrape / Sales Nav / PhantomBuster)
- Hands-only craft; workbench stamps after review
- Cap parallel micro-Hands; exclusive write paths
- Forbidden: Hunter/Apollo, pattern guessing, invented emails

### From W2
- Run **Website backfill + domain cleanup before** email crawl arms
- Monday Website wrong/parked is common — sniff-test before treating as firm
- Deferred high-yield URL packs beat another Form D / blind Wayback sweep
- Form D that lists name without email → EMPTY (do not promote)
- Wayback without prior mailto signal → deprioritize
- LinkedIn-only near-misses → HOLD (Maite, Jason pattern)

### From W3
- **No Pattern+SMTP** (hard) — search/public co-occurrence only
- Exhausted cohorts recycle EMPTY across arms — escalate methods, don’t re-seat the same EMPTY list without new leads
- Hygiene-gated single crawl can still FOUND when domains were wrong
- UNCERTAIN (e.g. Nathalie before later bind) → do not stamp

### From W4
- Person-named seats only on email arms (blank contact_name firm rows = hygiene queue)
- Press/speaker mailto + named PDFs highest yield; L04/L08/L10 blind sweeps ≈ 0
- Always check Monday Email blank before stamp (re-finds of Lucía/July/Justin/Jean-Marc)
- Quiet mid-wave: merge EMPTY silent; ping FOUND / HOLD / wave gate
- One deferred harvest wave after multi-method EMPTY recovers leads

## Unit of work

One **wave** = Email-blank **person-named** cohort + parallel **method arms** (cloud Hands).
Workbench coordinates / reviews / stamps; Hands never writes Monday.
