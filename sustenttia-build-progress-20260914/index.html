El problema que resolvimos

  • Informes inconsistentes — el mismo cuestionario podía producir narrativas distintas entre ejecuciones.
  • Sobre-corrección — el sistema rellenaba huecos con texto genérico no respaldado por la empresa.
  • Alucinaciones — referencias, cifras o casos que no existían en las respuestas del cliente.
  • Score ≠ evidencia — la puntuación ASG no siempre coincidía con lo que el informe afirmaba.
Objetivo: cada PYME recibe un informe trazable, repetible y alineado con su evidencia — no un texto creativo.

Arquitectura en una frase

Cuestionario (Fillout) + hechos bloqueados + plantillas + contrato fail-closed — el modelo de lenguaje es solo un enchufe, no el cerebro del producto.
📋

Entrada controlada

Fillout captura respuestas estructuradas. País, sector y horizontes vienen del cuestionario, no se inventan.

🔒

Salida verificable

Plantillas fijas + checklist automático. Si falta evidencia, el sistema deja vacío — no rellena.

  • Fail-closed: si un candado falla, el informe no avanza — se corrige o se deja explícito el vacío.
  • Trazabilidad: cada puerta queda registrada (qué pasó, qué no, por qué).
  • Sin atajos: no hay envío directo al cliente sin pasar revisión humana.
